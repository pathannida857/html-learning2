CSS ki display property

display decide karta hai ki element page par kaise dikhega aur doosre elements ke saath kaise arrange hoga.

1. display: block

Block element poori available width leta hai aur nayi line se shuru hota hai.

Block item 1 Block item 2

2. display: inline

Inline elements ek hi line mein aate hain. In par width aur height aam taur par apply nahi hoti.

Inline item 1 Inline item 2

3. display: inline-block

Inline-block items ek line mein aate hain, aur unki width aur height set kar sakte hain.

Item 1 Item 2 Item 3

4. display: none

Is property se element page par nahi dikhta aur uske liye khaali jagah bhi nahi rehti.

Yeh paragraph chhupa hua hai.

.hidden-example { display: none; }

5. display: flex

Flexbox items ko ek row ya column mein arrange karne ke liye kaam aata hai.

Flex 1 Flex 2 Flex 3

6. display: grid

Grid items ko rows aur columns mein arrange karta hai.

Grid 1 Grid 2 Grid 3
